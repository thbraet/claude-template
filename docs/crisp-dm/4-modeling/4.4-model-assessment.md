## Error Analysis

### Error Summary (XGBoost)
- **Correct:** 755 (84.7%)
- **False Negatives (missed survivors):** 85 — model predicted deceased but passenger survived
- **False Positives (false survivors):** 51 — model predicted survived but passenger perished
- **FP/FN ratio:** 0.60 — model is more conservative (misses more survivors than it falsely predicts)

### Prediction Confidence
- Most errors occur near the decision boundary (P(survived) close to 0.5)
- High-confidence errors are rare, indicating the model "knows what it doesn't know"
- Calibration is reasonable: predicted probabilities roughly track actual survival rates

![Error Analysis](../../reports/figures/assessment/error_analysis_xgboost.png)

### Worst Predictions
- **Worst false negatives (missed survivors):** Typically 3rd-class males who survived against the odds, or young children the model underweighted
- **Worst false positives (false survivors):** Typically 1st/2nd-class females who perished despite strong survival indicators (e.g., large families, late embarkation)

### Systematic Error Patterns

| Pattern | Description | Affected Segments | Severity |
|---------|-------------|------------------|----------|
| Gender/class conflict | Model struggles when gender and class signals conflict | 3rd-class females, 1st-class males | Medium |
| FN bias | More false negatives than false positives (85 vs. 51) | Males who survived, young children | Medium |
| Ambiguous passengers | 18.3% of passengers cause model disagreement; XGBoost accuracy drops to 69.9% in these cases | Cross-cutting: mixed class/age/family | High |

## Subgroup Performance

### By Passenger Class
![Accuracy by Sex x Pclass](../../reports/figures/assessment/accuracy_by_sex_pclass.png)

- **Pclass 1:** High accuracy — strong survival signal (high fare, cabin)
- **Pclass 2:** Moderate accuracy — intermediate survival rates
- **Pclass 3:** Most errors concentrated here — largest segment, most ambiguous survival patterns

### By Sex
- **Female:** Very high accuracy — dominant survival predictor
- **Male:** Lower accuracy — some males survived (especially boys, 1st class) and model misses some

### By Age Group
- **Children (0-12):** Model captures the "children first" signal but misses some 3rd-class boys
- **Teens/Adults:** Accuracy tracks overall average
- **Seniors (56+):** Small sample; slightly more variable performance

### By Fare Level
- **High fare:** High accuracy (strong Pclass correlation)
- **Low fare:** More errors (3rd-class ambiguity)

### By Family Size
- **Alone:** Moderate accuracy
- **Small families (2-3):** Best accuracy — families had survival advantage
- **Large families (6+):** Lowest accuracy — large families in 3rd class often perished together

### Underperforming Segments
No segments fall below 75% accuracy threshold. Two segments where XGBoost is worse than gender baseline were identified — likely small-sample noise in edge cases.

## Overfitting Assessment

| Model | Train Accuracy | Val Accuracy | Gap | Gap % | Verdict |
|-------|---------------|-------------|-----|-------|---------|
| Gender Baseline | 0.7868 | 0.7868 | 0.0000 | 0.00% | Good Fit |
| Logistic Regression | ~0.83 | 0.8283 | ~0.002 | ~0.2% | Good Fit |
| Random Forest | ~0.90 | 0.8462 | ~0.05 | ~5% | Borderline |
| XGBoost | ~0.92 | 0.8473 | ~0.07 | ~7% | Moderate Overfit |
| SVM (RBF) | ~0.86 | 0.8283 | ~0.03 | ~3% | Good Fit |

### Learning Curves
![Learning Curves](../../reports/figures/assessment/learning_curves.png)

- **Logistic Regression:** Train and validation converge — low variance, some bias. More data would not help significantly.
- **Random Forest:** Gap between train and validation persists — some overfitting, but controlled by `max_depth=8` and `min_samples_leaf=5`.
- **XGBoost:** Similar pattern to RF. Regularization (`subsample=0.7`, `colsample_bytree=0.7`) helps but train accuracy remains higher. On this small dataset, some gap is expected.

**Conclusion:** XGBoost has a moderate train-validation gap (~7%), which is typical for gradient boosted trees on 891 rows. The regularization settings are appropriate, and the validation performance is stable (CV std = 1.69%). This is acceptable for proceeding to evaluation.

## Model Agreement Analysis

- **All 5 models agree:** 728 passengers (81.7%) — accuracy 88.0% on these "easy" cases
- **At least 1 disagrees:** 163 passengers (18.3%) — accuracy drops to 69.9%
- The 163 disagreement passengers represent the "hard" cases at the decision boundary
- XGBoost and Random Forest have the highest pairwise agreement among the ML models

### Error Cost Asymmetry
- **False Positives (51):** Predicted survival for deceased passengers — over-optimistic

- **For Kaggle:** FP and FN are equally costly (each costs 1 correct prediction)

## Model Selection Recommendation

### Recommended Model

| Attribute | Value |
|-----------|-------|
| **Model** | XGBoost (`n_estimators=100`, `max_depth=6`, `learning_rate=0.05`, `subsample=0.7`, `colsample_bytree=0.7`) |
| **MLflow Run ID** | `xgboost-tuned-20260331` |

| **Justification** | Best accuracy, F1, and ROC-AUC across all models; meets all minimum success criteria; moderate overfitting is controlled and expected for this dataset size |
| **Known Limitations** | Does not reach 85% target; struggles with ambiguous passengers (3rd-class females, 1st-class males); FN-biased (misses more survivors than it falsely predicts) |
| **Production Risks** | N/A — one-time Kaggle submission, not a production deployment |

### Runner-Up

| Attribute | Value |
|-----------|-------|
| **Model** | Random Forest (`n_estimators=100`, `max_depth=8`, `min_samples_leaf=5`, `max_features=0.5`) |
| **Primary Metric** | 84.62% CV accuracy (+7.55% vs. baseline) |
| **Justification** | Near-identical performance; simpler; better interpretability via Gini importance |

### Recommended Next Phase

**Proceed to Evaluation (Phase 5)**

**Rationale:** XGBoost meets all minimum success criteria. The 85% target is not reached (84.73%) but is within noise of the threshold. On an 891-row dataset with fundamental ambiguity in passenger survival, further tuning has diminishing returns. The appropriate next step is stakeholder review and Kaggle submission for true test accuracy.

**If Kaggle accuracy < 80% (unexpected):**
1. Try a simple voting ensemble of XGBoost + RF + LR
2. Revisit feature engineering (ticket group patterns, cabin section features)
3. Try stacking with a meta-learner
