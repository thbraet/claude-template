# 4.3 Model Building Report

> **Project:** Titanic Survival Prediction
> **Date:** 2026-03-31
> **CRISP-DM Phase:** 4. Modeling
> **Status:** Draft

---

## Build Overview

- **Techniques Built:** Gender Baseline, Logistic Regression (L2), Random Forest, XGBoost, SVM (RBF)
- **Data Used:** `data/processed/train_formatted.csv` (891 rows, 26 features)
- **Splitting Strategy:** Stratified 5-fold CV (`random_state=42`, no separate hold-out)
- **Training Period:** N/A (single historical event — April 15, 1912)
- **Validation Period:** 5-fold CV (~178 rows per fold)
- **Test Period:** Kaggle test set (418 passengers) — held out, used only for final submission
- **MLflow Experiment:** `titanic-survival-modeling`
- **Total Runs:** 9 (1 baseline + 4 default + 4 tuned)

---

## Data Pipeline

- **Input data:** `data/processed/train_formatted.csv` — output of Phase 3 (data preparation)
- **Preprocessing steps:**
  - LR and SVM: `StandardScaler` inside `Pipeline` (fit per CV fold to prevent leakage)
  - RF and XGBoost: no scaling (tree-based)
- **Feature set:** 26 features (Pclass, Sex, Age, Fare, FareLog, SibSp, Parch, FamilySize, FamilySizeBin, IsAlone, HasCabin, TicketGroupSize, AgeMissing, Deck_A–T, Embarked_Q/S, Title_Master/Miss/Mrs)
- **Preprocessing fit:** Training set only (validated: yes)
- **Code location:** `notebooks/4.3-model-building.ipynb`

## Baseline Model

### Configuration
- **Technique:** Gender-only rule (female=survived, male=perished)
- **Parameters:** None
- **MLflow Run:** `gender-baseline-baseline-20260331`

### Results (5-Fold CV)
| Metric | Value |
|--------|-------|
| Accuracy | 0.7868 ± 0.0188 |
| F1 | 0.7094 ± 0.0316 |
| ROC-AUC | N/A (rule-based) |

### Observations
- Matches expected ~78.7% accuracy from 4.2 test design
- Captures the dominant predictor (Sex) but ignores all other features
- Sets the floor: every model must beat 0.7868 + 0.035 = 0.822 to justify complexity
