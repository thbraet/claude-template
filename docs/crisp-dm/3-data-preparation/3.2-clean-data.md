## Cleaning Overview

- **Input data:** train.csv (891 rows × 12 cols) + test.csv (418 rows × 11 cols) from 3.1 selection
- **Quality issues addressed:** 4 out of 7 from 2.4 (3 minor issues left as-is per 2.4 recommendation)
- **Cleaning approach:** Conservative — impute missing values only, no record removal
- **Key principle:** Raw data is immutable — all cleaning applied to copies; imputation fitted on training data only

## Cleaning Plan

| # | Issue (from 2.4) | Category | Severity | Fields Affected | Records Affected | Treatment | Rationale |
|---|-----------------|----------|----------|-----------------|-----------------|-----------|-----------|
| 1 | Age 20% missing (MAR) | Missing | Major | Age | 177 train, 86 test | Title-group median imputation + AgeMissing indicator | MAR pattern — naive imputation would bias; title captures age signal well |

## Missing Value Treatment

### Summary
| Field | Missing Count | Missing % | Pattern | Treatment | Rationale |
|-------|--------------|-----------|---------|-----------|-----------|
| Age (train) | 177 | 19.9% | MAR | Impute with title-group median | Correlated with Sex/Pclass; title medians preserve group structure |
| Age (test) | 86 | 20.6% | MAR | Impute with title-group median (from train) | Same strategy, parameters from train only |
| Embarked (train) | 2 | 0.2% | MCAR | Impute with mode ('S') | Trivial; mode from train |
| Fare (test) | 1 | 0.2% | MCAR | Impute with Pclass 3 median (8.05) | Single record; Pclass-conditional from train |
| Cabin (both) | 687 / 327 | 77.1% / 78.2% | MNAR | Deferred to 3.3 | Engineering operation (Deck, HasCabin), not cleaning |

### Imputation Details
| Field | Method | Parameters | Fit On | Notes |
|-------|--------|-----------|--------|-------|
| Age | Title-group median | Master: 3.5, Miss: 21.0, Mr: 30.0, Mrs: 35.0 | Training set only | Rare titles mapped to common groups (e.g., Dr→Mr, Mlle→Miss) |
| Embarked | Mode | 'S' (Southampton) | Training set only | 72.4% of train passengers |
| Fare | Pclass-conditional median | Pclass 1: 60.29, Pclass 2: 14.25, Pclass 3: 8.05 | Training set only | Only 1 test record affected (Pclass 3) |

### Missing Value Indicator Variables
| Original Field | Indicator Field | Purpose |
|---------------|----------------|---------|
| Age | AgeMissing | Captures missingness signal — survival rate 29.4% (missing) vs 40.6% (present) |

## Cleaning Code

### Pipeline Location
- **Module:** `src/cleaning.py` — `compute_imputation_params()` + `clean_dataset()`
- **Notebook:** `notebooks/3.2-clean-data.ipynb`
- **Dependencies:** pandas, numpy, re (standard library)

### Reproducibility Notes
- Imputation parameters computed from training set only via `compute_imputation_params(train_df)`
- Same parameters applied to both train and test via `clean_dataset(df, params)`
- Cleaning is idempotent — running twice produces identical results (verified in notebook)
- Raw data is never modified — outputs written to `data/processed/`
- No random seeds needed (deterministic imputation)

### Output Files
- `data/processed/train_clean.csv` — 891 rows × 13 cols
- `data/processed/test_clean.csv` — 418 rows × 12 cols
