## Decision: Deploy

### Rationale

The project has met all minimum business success criteria and data mining success criteria on out-of-fold estimates. XGBoost achieves 84.73% OOF accuracy, exceeding the 80% competitive threshold by 4.7 percentage points and the 78% minimum by 6.7 percentage points. The single deployment condition from 5.1 — confirming accuracy on Kaggle's test set — is itself a Phase 6 activity (Kaggle submission), making iteration unnecessary to resolve it.

The process review (5.2) confirms strong methodology execution across all 18 CRISP-DM artifacts with no critical technical gaps. The 18.3% "ambiguous passenger" analysis from 4.4 demonstrates that the practical accuracy ceiling for single models on this dataset is ~84-85%, meaning further modeling iterations would yield diminishing returns. The time and effort required to iterate (return to Phase 3 or 4) is not justified by the expected marginal improvement.

The two outstanding gaps — incomplete ablation study and pending stakeholder sign-offs — are both addressable during Phase 6 without blocking the Kaggle submission. The ablation study (DM4) was scoped as a nice-to-have in the project plan (1.4), and feature importance analysis already provides a substantive answer to BQ4. Stakeholder review by Bart Mollet can occur in parallel with deployment activities.
