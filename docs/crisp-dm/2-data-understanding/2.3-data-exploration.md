| Group | Survival Rate | Count | Notes |
|-------|--------------|-------|-------|
| Female, 1st class | 96.8% | 91/94 | Near-certain survival |

This interaction is the single most informative pattern in the data. Sex alone is insufficient — 3rd-class women had a coin-flip survival rate, while 1st/2nd-class women were nearly guaranteed survival.

### Multicollinearity Concerns

| Feature Pair | Correlation | Risk | Recommendation |
|-------------|-------------|------|----------------|
| Pclass — HasCabin | -0.726 | High | HasCabin largely redundant with Pclass (1st class had cabins); use Deck where available, otherwise Pclass captures the signal |
| SibSp — FamilySize | +0.891 | High | FamilySize = SibSp + Parch + 1 — by construction. Use FamilySize (or binned version) instead of SibSp/Parch separately |
| Parch — FamilySize | +0.783 | High | Same as above |
| Pclass — Fare | -0.549 | Medium | Both capture socio-economic status; tree models handle this, but logistic regression may see inflated standard errors |
| FamilySize — IsAlone | -0.691 | Medium | IsAlone is a binary threshold of FamilySize — use one or the other, not both |

| 5 | Small dataset favors regularized models (from 1.3) | 891 training rows; SibSp and Parch show extreme kurtosis (17.8, 9.7) | Overfitting risk real; cross-validation essential; prefer ensemble methods |

### Surprising Findings

| # | Finding | Evidence | Implication |
|---|---------|----------|-------------|
| 1 | Age is NOT statistically significant as a linear predictor | Mann-Whitney p=0.16; correlation with survival only r=-0.077 | Age's effect is non-linear (infants high, elderly low, middle flat). Need age bins or interaction with Sex |
| 2 | Family size has an inverted-U survival pattern | Size 2-4: 55-72% survival; Size 1: 30%; Size 5+: 0-20% | Binary IsAlone is too coarse — a 3-level FamilySize bin (Small/Medium/Large) captures the pattern better |

| 4 | Age missingness correlates with survival | Missing Age: 29.4% survival; Known Age: 40.6% | Create an AgeMissing indicator feature — missingness itself carries signal |
| 5 | Zero-fare passengers are all male with near-zero survival | 15 passengers, 6.7% survival, all male | Small group but distinct; Fare=0 may need special handling |

## Modeling Implications

- **Transformations suggested:**
  - Log-transform Fare (skew=4.78, kurtosis=33.2) — improves symmetry and reduces outlier influence
  - Bin Age into meaningful groups (0-5, 6-12, 13-18, 19-35, 36-60, 61+) or use as continuous with non-linear models
  - One-hot encode Embarked (3 categories); ordinal encode Pclass (natural ordering)

- **Feature engineering priorities:**
  1. Title extraction (highest signal-to-effort ratio)
  2. FamilySizeBin (captures non-linear family size effect)
  3. log(Fare) transformation
  4. HasCabin indicator
  5. AgeMissing indicator

- **Model family considerations:**
  - **Tree ensembles** (Random Forest, Gradient Boosting) are ideal: handle interactions (Sex x Pclass) natively, robust to outliers, no scaling needed, work well with small datasets when regularized
  - **Logistic Regression** needs explicit interaction terms (Sex*Pclass) and feature scaling; useful as interpretable baseline
  - **SVM** may work given small dataset size but requires scaling and is less interpretable
  - The strong Sex x Pclass interaction pattern favors models that capture feature interactions automatically

- **Segmentation needs:** No separate models needed — a single model with appropriate features and interactions should suffice. The dataset is too small (891 rows) to support meaningful segment-specific models.

- **Data preparation priorities:**
  1. Age imputation (20% missing) — use title-group medians (Mr: ~30, Mrs: ~36, Miss: ~22, Master: ~4)
  2. Embarked imputation (2 missing) — mode fill ('S')
  3. Test set Fare imputation (1 missing) — median fare for same Pclass
  4. Handle zero-fare passengers (n=15) — investigate but likely leave as-is
