## Initial Observations

### Red Flags
| # | Dataset | Field(s) | Observation | Severity | Action Needed |
|---|---------|----------|-------------|----------|---------------|
| 1 | train + test | Cabin | 77–78% missing — too sparse for direct use as a feature | High | Extract deck letter (A–G) where available; create binary `has_cabin` indicator; investigate if missingness correlates with class/survival |
| 2 | train + test | Age | ~20% missing in both sets — a key predictor | Medium | Impute using title-group medians (Mr., Mrs., Miss., Master.); validate imputation quality via CV |
| 3 | train | Fare | Contains 0.00 values (minimum) — passengers with zero fare | Low | Investigate: are these crew, children, or data errors? 15 passengers have Fare=0 |
| 4 | test | Fare | 1 missing value (PassengerId 1044) | Low | Impute with median fare for same Pclass |
| 5 | train | Embarked | 2 missing values | Low | Impute with mode ('S' — Southampton, 72.4% of passengers) |
| 6 | train | Cabin | Deck 'T' appears once — likely anomaly or typo | Low | Investigate; may merge with nearest deck or drop |

### Noteworthy Patterns
- **Class imbalance is moderate** (38.4% survived) — no resampling needed, but stratified CV is essential
- **Pclass skewed toward 3rd class** (55.1%) — majority of passengers were lower class
- **Male majority** (64.8% train, 63.6% test) — consistent across both sets
- **Southampton dominant** (72.4% train, 64.6% test) — slight distribution shift between train/test
- **Fare is heavily right-skewed** (mean 32.20, median 14.45, max 512.33) — log transformation likely beneficial
- **SibSp and Parch are zero-inflated** (median=0 for both) — most passengers traveled alone
- **Ticket sharing:** 681 unique tickets for 891 passengers — some tickets are shared by family/travel groups (top ticket "347082" shared by 7 passengers)
- **Cabin contains multi-cabin entries** (e.g., "B57 B59 B63 B66") — some passengers had multiple cabins
- **Train/test distributions are comparable** for Pclass, Sex, Age, SibSp, Parch, Fare — no obvious covariate shift

### Contradictions with Prior Documents
- No contradictions found. All observations align with expectations from 1.2 (situation assessment) and 1.3 (data mining goals).
